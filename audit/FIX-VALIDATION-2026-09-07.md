## 验证边界

本次没有在用户电脑上开启/修改系统代理、安装或删除 CA，也没有实际安装或卸载产品。注册表恢复策略有单元测试，证书查询和维护入口有运行验证，但真实注册表写入、证书新增/删除以及完整升级卸载仍需要独立 Windows 虚拟机验收。不能把本次通过的界面测试等同于所有网络环境下都不会白屏。

依赖漏洞数据库在线核验未完成：官方 npm audit 接口连接被重置，npmmirror 返回审计 API 未实现。没有把空结果解释为“没有漏洞”。构建保留 caniuse-lite 数据较旧的非阻断提示。

本次验收平台是 Windows x64。macOS/Linux 原有系统代理和证书自动修改缺乏可靠归属保护，现明确返回需手动配置；尚未实现并验收这些平台的自动管理。第三方 Whistle 插件的全部协议行为也不在本次验证覆盖范围。

所有修复保留在工作区，没有创建提交或发布安装包到远端。
